# Task 1: Logistic Regression for Binary Classification

## Objective

The objective of this task is to develop a Logistic Regression model capable of predicting binary outcomes using supervised machine learning. The model is trained, evaluated, and interpreted using standard classification metrics.

## Dataset

- **Dataset:** Sentiment Dataset
- **Problem Type:** Binary Classification
- **Target Variable:** Sentiment

## Tools & Libraries

- Python
- Google Colab
- pandas
- NumPy
- scikit-learn
- matplotlib

## Steps performed

- Loaded and explored the dataset.
- Performed data preprocessing.
- Encoded categorical variables where required.
- Split the dataset into training and testing sets.
- Trained a Logistic Regression classifier using scikit-learn.
- Generated predictions on the test dataset.
- Evaluated model performance using multiple classification metrics.

## Evaluation Metrics

The model was evaluated using:

- Accuracy
- Precision
- Recall
- ROC Curve
- Confusion Matrix

## Outcome

A Logistic Regression classifier was successfully implemented for binary classification. The model's performance was evaluated using standard classification metrics, demonstrating its ability to classify unseen data effectively.
