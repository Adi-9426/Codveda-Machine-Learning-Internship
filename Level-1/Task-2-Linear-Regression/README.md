# Task 2: Linear Regression for House Price Prediction

## Objective

The objective of this task is to build and evaluate a Linear Regression model for predicting house prices using various housing-related features.

## Dataset

- **Dataset:** House Price Prediction Dataset
- **Target Variable:** MEDV (Median Value of Owner-Occupied Homes)

## Tools & Libraries

- Python
- Google Colab
- pandas
- NumPy
- scikit-learn
- Matplotlib

## Methodology

- Loaded the housing dataset.
- Performed data preprocessing and explored the dataset.
- Split the dataset into training and testing sets.
- Trained a Linear Regression model.
- Predicted house prices on the test dataset.
- Evaluated the model using regression performance metrics.

## Evaluation Metrics

The model was evaluated using:
- Mean Squared Error (MSE)
- R² Score (Coefficient of Determination)

## Outcome

A Linear Regression model was successfully developed to predict house prices based on multiple housing features. The model's performance was evaluated using standard regression metrics.
