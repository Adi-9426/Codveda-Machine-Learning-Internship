# Task 1: Data Preprocessing for Machine Learning

## Objective

The objective of this task is to preprocess a raw dataset by handling missing values, encoding categorical variables, standardizing numerical features, and splitting the dataset into training and testing sets.

## Dataset

- **Dataset:** Iris Dataset
- **Source:** Local CSV file (`iris.csv`)

## Tools & Libraries

- Python
- Google Colab
- pandas
- scikit-learn

## Steps Performed

- Loaded the Iris dataset.
- Checked for missing values.
- Handled missing values using the mean for numerical features.
- Encoded the target variable (`species`) using Label Encoding.
- Standardized numerical features using `StandardScaler`.
- Split the dataset into training and testing sets using an 80:20 ratio.

## Outcome

The dataset was successfully preprocessed and prepared for use in machine learning models.
